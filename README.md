One sentence, at most 200 characters, explaining the modern internet to
someone arriving from the year 1800 — built only from things a person from
1800 already knows: a road, a post office, a library, a market.

## The entry

> The internet is every library, post office and market in the world joined by a single road, where a letter arrives the moment it is written and any book can be read from your chair.

## Run it

```sh
node main.ts   # writes /output/entry.txt
```
